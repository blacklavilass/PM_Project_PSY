# Проектный менеджмент - практика

Материалы и результаты пяти фаз практики.

## Команда

- Попов Виталий
- Стрельников Максим
- Ячный Марк

**Таск-трекер:** _https://ru.yougile.com/board/olwy02cu39td_

## Фазы

| Фаза | Папка | Содержание |
|---|---|---|
| 1. Выбор концепции | `phase-1/` | >=4 концепции и >=4 критерия, трёхточечные экспертные оценки, выбор варианта нечётким коллективным TOPSIS и чётким коллективным МАИ, сравнение результатов |
| 2. Распределение работы (мета) | `phase-2/` | декомпозиция работ фазы 3, экспертная оценка сложности, индивидуальные предпочтения, постановка и решение задачи распределения |
| 3. Оценка проекта | `phase-3/` | >=10 Use Cases, оценка в COSMIC FP и Use Case Points, коллективная экспертная оценка, выводы о масштабе, составе команды и сроке |
| 4. Прогнозирование (мета) | `phase-4/` | декомпозиция работ фазы 5, трёхточечные оценки, две модели Монте-Карло (по числу задач за неделю и по трудозатратам), срок с 80% достоверностью |
| 5. Планирование | `phase-5/` | 20–25 задач проекта, состав команды как типы ресурсов, ресурсные требования и связи предшествования, перебор эвристик упорядочения, календарный план на 40-часовую неделю |
